# Sales Performance Dashboard

## Project Overview

This project is a **Sales Performance Dashboard** created using **Power BI and Excel**. The dashboard helps analyze sales performance across different cities, customers, and product categories. It provides insights into revenue, profit, orders, and monthly sales trends.

---

## Tools Used

* **Power BI** – Data visualization and dashboard creation
* **Microsoft Excel** – Data cleaning and preparation

---

## Dashboard Features

* Total Sales
* Total Profit
* Total Orders
* Average Order Value
* Monthly Sales Trend
* Sales by City
* Sales by Category
* Top 5 Customers by Sales
* Interactive filters and slicers

---

## Key Insights

* Identified top-performing cities and customers.
* Tracked monthly sales growth.
* Compared sales performance across product categories.
* Improved understanding of business performance through interactive visuals.
